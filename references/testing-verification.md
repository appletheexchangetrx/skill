# Testing and Verification

Discover actual project scripts and available CI. Select checks proportionate to changes and risk:
- Production build.
- TypeScript/type checks.
- Lint.
- Unit, integration, and end-to-end tests.
- Accessibility, responsive, security, and regression checks.
- API/integration contract checks.

Statuses: Passed, Failed, Not Run, Not Verified, Not Applicable.

Record exact command/tool, scope, outcome, and relevant error summary. Do not say a test passed if it was not run. If execution is unavailable, provide reproducible commands and mark Not Run. Review diffs for scope drift, accidental secrets, and generated artifacts before PR.
