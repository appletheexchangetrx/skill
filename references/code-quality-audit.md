# Code Quality Audit

Assess architecture, cohesion, coupling, naming, duplication, component size, hook correctness, state ownership, type safety, error handling, async cancellation/races, input validation, and maintainability.

Trace imports and runtime data flows before recommending refactors. Avoid subjective findings without impact. Prefer focused, incremental changes and explicit acceptance criteria. Check for dead code and unused dependencies, but verify before removal.
