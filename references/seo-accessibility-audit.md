# SEO and Accessibility Audit

SEO: title, description, canonical strategy where relevant, indexability, robots/sitemap, Open Graph, structured data when appropriate, SPA rendering constraints, and meaningful URLs.

Accessibility: semantic landmarks, heading order, labels, accessible names, alt text, focus visibility, keyboard operation, contrast, reduced motion, status announcements, and error identification.

Source inspection does not prove conformance. Mark automated/manual checks Not Run unless executed and report limitations.
