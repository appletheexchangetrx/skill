# Installation and Usage

## Installation
Install/import this Skill using the ChatGPT skill mechanism supported by the user's environment. Exact availability and UI steps depend on the ChatGPT client and account configuration.

## Required connections
- GitHub connection with repository read access; write access is needed only for approved branch/file/commit/PR operations.
- Supabase connection is optional and needed only for Repository + Supabase mode.

## First run
1. Start the Skill.
2. Select an accessible repository and branch.
3. Choose Repository Only or Repository + Supabase.
4. Review inventory, coverage, and audit findings.
5. Choose an improvement group.
6. Approve its implementation plan.
7. Review verification results and the Pull Request.

## Safety
Do not paste secrets into chat or commit them to the repository. Grant only the permissions required for the task. The user independently tests the completed Skill; installation does not imply successful testing.
